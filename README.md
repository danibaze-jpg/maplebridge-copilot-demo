# MapleBridge Copilot Demo

A single-page, click-through demo of the MapleBridge adviser copilot, built for Team Smith's SAIBS 2026 case competition entry (Smith School of Business, Queen's University).

Everything lives in one file, `index.html`. No build step, no dependencies beyond Google Fonts.

## Run it

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Publish with GitHub Pages

Settings, Pages, Source: "Deploy from a branch", branch `main`, folder `/ (root)`. The demo will be live at `https://<your-username>.github.io/maplebridge-copilot-demo/` a minute or two later.
